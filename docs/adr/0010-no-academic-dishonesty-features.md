# No features that enable academic dishonesty or misrepresentation

This project adds functionality that makes genuine, honest use of Lectio easier — it must never add functionality whose purpose or effect is to help a student or teacher misrepresent themselves, fabricate a record, or substitute automation for input that is supposed to be their own honest work or reflection. Concretely out of scope: auto-generating or auto-filling a fravær (absence) excuse/justification, auto-completing elevfeedback (student feedback/evaluation) on a student's behalf, or any similar shortcut whose function is to make it look like a person did something they didn't.

This is a guardrail on *purpose*, not a ban on adjacent, legitimate convenience. A script may still remind someone that feedback is due, deep-link to the right form, or surface their own attendance history to them — the line is authorship and honesty of the actual submitted content: a human must still be the one who decides what an absence excuse says or what a feedback answer is.

## Why

Lectio is a school's administrative record. A widely-installed community tool that made it easier to falsify that record, or to skip genuine reflection Lectio requires, would undermine the trust schools and Lectio itself place in letting these scripts run at all — and would put every other module in this project at risk of a school banning the whole thing over one bad feature.

## Consequences

- Reject or decline any issue, request, or contribution whose core function is deception, fabrication, or bypassing a requirement meant to reflect a student's or teacher's own input — regardless of how it's framed (e.g. "just a template," "just saves time").
- When scoping a new convenience feature, check it against: *does this let someone present something as their own genuine input when it wasn't?* If yes, it doesn't belong in this project even if technically easy to build.
